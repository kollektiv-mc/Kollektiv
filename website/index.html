[i] about

Build and play on your own terms.

Kollektiv is a suite of tools for Minecraft: Java Edition. It opens up the technical side of building and playing, and gives you the flexibility and freedom to shape it, without asking you to be technical.

[≡] architecture

A few fixed ideas

Local and private

The tools run on your machine, against files you already have. No account, no cloud, no telemetry.

Made to work together

One design language across the suite, and tools designed to hand work to each other. Learning one is most of learning the next.

A window, not a terminal

Every tool puts a UI in place of a console, a config file or memorised syntax, and keeps the power that came with them.

In the open

Source, roadmaps and issues are public on GitHub, for every tool in the suite.
