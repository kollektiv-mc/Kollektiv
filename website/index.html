One suite. Two tools.

Kollektiv is a small suite of tools for Minecraft: Java Edition. Konnekt runs the server; Kommands writes the commands. Separate apps, one design.

[≡] architecture

Two apps, built alike

Separate apps

Konnekt and Kommands are two codebases with their own releases. Nothing you install for one is needed by the other.

Local-first

Konnekt runs on your own machine, against server folders you already have. Kommands' desktop build works with no internet at all.

Versioned game data

Command syntax and game values are held per Minecraft version, so what Kommands generates matches the version you target.
